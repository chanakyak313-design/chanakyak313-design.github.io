# Karra Chanakya — Portfolio

A high-performance, brutalist-modern portfolio website built with clean semantic HTML5, modern CSS3, vanilla JavaScript, GSAP ScrollTrigger, and a client-side AI assistant.

## Features
- **Hero Terminal Simulator**: Dynamic typewriter animation simulating interactive CLI commands.
- **GSAP ScrollTrigger & Parallax**: Smooth fluid parallax, 3D card tilt effects, and magnetic CTA buttons.
- **Stats Counter**: Real-time animated number counters for LeetCode problems (500+), projects, and metrics.
- **Projects Showcase & Dynamic Filtering**: Instant category filtering across Enterprise AI, Full-stack, Live/Cloud, and Systems.
- **Beyond the Build / Deep Dive Carousel**: Interactive 6-slide visual photo/architecture carousel with play/pause, dot navigation, and auto-advance.
- **Dynamic Contact Generator**: Hiring role chips that automatically format pre-filled Gmail correspondence.
- **Client-Side AI Chatbot**: Built-in interactive assistant answering questions about Chanakya's background, Salesforce Agentforce certification, projects, education, and contact channels.
- **Downloadable Resume**: Direct 1-click links to `Chanakya_Karra_Resume.pdf`.

## Running Locally

### Option 1 (Windows double-click):
Double-click `start-site.bat`. Your default web browser will automatically open to `http://127.0.0.1:<port>/`.

### Option 2 (Python CLI):
```bash
python start_site.py
```
Or:
```bash
python -m http.server 8000
```
Then open [http://localhost:8000](http://localhost:8000) in your browser.
